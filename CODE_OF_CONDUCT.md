# Code of Conduct

This project is for practical collaboration around game-localization workflow tooling. Keep discussions focused, specific, and useful.

## Expected Behavior

- Be direct and respectful.
- Critique ideas, code, docs, and workflows rather than people.
- Use concrete examples when reporting problems.
- Keep private localization data out of public discussion.
- Assume contributors may come from localization, engineering, QA, or production backgrounds.

## Unacceptable Behavior

- Harassment, threats, or personal attacks.
- Publishing another person's private information.
- Posting private customer strings, workbooks, screenshots, keys, or logs.
- Repeatedly derailing issues or pull requests away from the stated workflow problem.
- Spam or low-effort promotional comments.

## Enforcement

Maintainers may remove comments, close issues, block users, or reject contributions that violate this code of conduct.

If a conduct issue includes sensitive information, report it through a private channel instead of posting more details publicly.
