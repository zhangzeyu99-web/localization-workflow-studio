游戏翻译本地化项目工作台

面向游戏语言包与公告外文本的本地工作台。项目资料、术语、译文归档、AI 翻译、QA 校对和交付文件在本地后端闭环运行；v1.6.1 使用同一源码、前端构建和通用包，支持本地 local/off 与线上 cloud/required 两种生产运行配置；GitHub Pages 只提供公开说明，不承载真实项目数据。

语言包翻译

  • 导入完整语言表。
  • 项目 brief 主导提示词。
  • 后台分批翻译、断点续跑。
  • 最终输出译文 Excel 与修改记录。

术语与 QA

  • 完整语言表先扫描候选，人工确认后入库。
  • 译文归档按语言隔离并支持宽表展示。
  • 检查 ID、变量、标签、中文残留、术语命中。

公告外文本

  • 项目内公告任务。
  • 先提公告术语，再反查 QA 归档和语言表。
  • 支持 AI 翻译、QA 回填和 ZIP 交付。

需要私有配置

真实 API key 写入本地数据目录的 `settings.local.json`，不要提交到 GitHub、Pages、截图或公开 issue。

不依赖 Agent

工作台正式链路由本地后端和已配置 AI Provider 执行。Codex 只用于开发、排障或人工辅助。

公开页面限制

这里不是在线工作台。完整功能必须在本机或可信局域网启动后端与前端。
