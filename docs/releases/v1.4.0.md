# v1.4.0 线上部署说明

发布日期：2026-07-15

## 本次变更

- 正式语言表与快速任务/公告改为两条独立的持久化 FIFO：每条通道全局同时运行 1 个，同一项目可跨通道并行。
- 等待任务在服务重启后继续排队；重启时正在执行的任务暂停为“服务重启，请继续”，不会自动重复调用模型。
- 顶部后台面板、任务页状态和项目“后台 N”角标统一以真实队列为准，并显示通道、操作人、排队位置和取消入口。
- 启动时自动清理旧版孤立 QA；已完成的翻译结果和交付产物不会回退。
- 快速任务与公告继续生成下载产物，但不再自动写项目译文归档；正式语言表通过 QA 后仍正常归档。
- 逐行校对状态已中文化；部署包会同时生成外部 `.zip.sha256` 校验文件。

## 运维部署

1. 校验部署包：`sha256sum -c localization-workflow-studio-online-v1.4.0-20260715.zip.sha256`。
2. 解压到全新的版本目录，不覆盖旧目录；保留版本目录之外的数据目录和 `/etc/lwstudio/settings.local.json`。
3. 从包内 `PACKAGE_MANIFEST.json` 读取 `git_sha`，写入 `/etc/lwstudio/lws.env` 的 `LWS_GIT_SHA`。
4. 确认后端只启动单 worker；本版本的任务提交/取消线性化以单 worker 为部署约束。
5. 原子切换 `/srv/lwstudio/current` 到新版本目录并重启服务，不要先停止旧目录后再覆盖文件。
6. 按包内 `ONLINE_DEPLOY_README.zh-CN.md` 运行部署检查，确认 `/api/version` 为 `1.4.0`、Git SHA 与静态资源清单一致。

## 上线验收

1. 在同一项目启动一条正式语言表任务和一条快速任务，确认两条通道同时运行。
2. 再提交第二条快速任务，确认显示正确 FIFO 位置，并在第一条完成后自动运行。
3. 确认两类产物均可下载，任务完成后顶部面板和项目“后台 N”角标立即清除。
4. 确认快速任务和公告没有增加项目译文归档，正式语言表通过 QA 后仍增加归档。
5. 确认升级前残留的孤立 QA 自动变为已取消，既有翻译结果和交付文件仍可下载。
