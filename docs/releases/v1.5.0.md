# v1.5.0 线上部署说明

发布日期：2026-07-16

## 本次变更

- 云端默认强制登录，新增服务端会话、argon2id 密码哈希、首次登录强制改密和登录防爆破。
- 新增 `admin`、`ops`、`member` 三档角色与项目成员关系；后端路由能力表 fail-closed，前端按权限隐藏或禁用操作。
- 保留 v1.4.0 的持久化双通道队列、重启恢复、排队可见性和取消审计，并把账号身份接入操作留痕和项目可见性。
- 正式翻译、快速任务和公告任务的“继续当前任务 / 放弃并新建 / 查看历史交付”生命周期已统一；旧任务异步结果不会污染新任务。
- 术语和译文归档导入增加预检、提交、覆盖统计和回滚；快速任务与公告只读取归档作为软参考，不回写归档。
- 越南语使用内部代码 `VN`；英语输入只保留 `EN`，不再显示或写入 `EN2`。

## 升级前准备

1. 备份完整 `/srv/lwstudio/data` 和 `/etc/lwstudio/lws.env`。
2. 解压到新的只读 release 目录，不覆盖 v1.4.0 目录。
3. 安装更新后的 `backend/requirements.txt`，确认 `argon2-cffi` 安装成功。
4. 从 `PACKAGE_MANIFEST.json` 读取 `git_sha`，写入 `LWS_GIT_SHA`。
5. 在首次启用认证且用户表为空时，临时设置 `LWS_ADMIN_USER` 和 `LWS_ADMIN_PASSWORD`，或运行 `scripts/create_admin.py`。

## 上线步骤

1. 保持单实例、单 uvicorn worker 和版本目录外的持久化数据目录。
2. 原子切换 `/srv/lwstudio/current` 后重启后端，再校验并重载 Nginx。
3. 初始管理员登录后完成强制改密；随后从环境文件移除 `LWS_ADMIN_PASSWORD` 并重启服务。
4. 不要删除 v1.4.0 release，直到 v1.5.0 的登录、权限、队列和真实业务流程全部验收通过。

## 上线验收

```bash
PACKAGE_GIT_SHA="$(python3.11 -c 'import json; print(json.load(open("PACKAGE_MANIFEST.json", encoding="utf-8"))["git_sha"])')"
python3.11 scripts/deployment_check.py \
  --base-url https://ai-lwstudio.example.com \
  --require-cloud \
  --require-provider \
  --expect-version 1.5.0 \
  --expect-git-sha "$PACKAGE_GIT_SHA" \
  --check-frontend-assets frontend/dist/assets \
  --auth-user admin \
  --auth-password '管理员密码'

python3.11 scripts/stability_check.py \
  --base-url https://ai-lwstudio.example.com \
  --auth-user admin \
  --auth-password '管理员密码'
```

必须确认：

- `auth_fail_closed` 为 `ok=true`，未登录访问业务 API 返回 401。
- 管理员、运营、普通成员的项目可见性和操作权限符合 `docs/ROUTE_CAPABILITIES.md`。
- 正式任务与快速任务/公告两条通道可并行，各自 FIFO；重启恢复、继续和取消不串任务。
- 公网 HTML、`/api/version` 静态资源清单和包内 `frontend/dist` 一致，版本为 `1.5.0`，Git SHA 与 manifest 一致。
- 管理员登录后的上传探针和完整稳定性流程通过。

## 回滚

代码回滚前先确认 v1.4.0 能读取升级后的数据库结构。若不能，停止服务并恢复升级前的完整数据备份，再把 `current` 切回 v1.4.0；不要只回滚 SQLite 而遗漏上传文件和任务产物。
