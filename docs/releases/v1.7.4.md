# v1.7.4：术语导入与流程恢复

发布日期：2026-10-10

## 本次更新

- 术语表不再按 1000 条硬拦截。上传文件先存档，预览与确认后才写入术语库。
- 自动识别工作表和语种；保留用户手动选择，单列译文只允许一种目标语言。
- 冲突按原表行分组，可编辑、忽略、仅保留组内一条，并重新预览；所有选择只影响本次入库，不修改源文件。
- 缺中文源文和无效 JSON 语种不再静默漏行。缺源文可补齐；语种未确定时可忽略或回源文件修正。
- 编辑术语时展开其他语种不会误清空已有译文；候选取消后恢复原内容。
- 提交响应丢失时核对原批次，支持同一批次安全重试，不再误报“未写入”或锁死恢复入口。

## 部署包

- `无账号-v1.7.4.zip`：固定为 `cloud/off`，仅用于有网络访问控制的可信内网，禁止直接暴露到公网。
- `有账号-v1.7.4.zip`：保留登录及项目权限，默认 `cloud/required`。
- 使用包内 `DEPLOY_README.zh-CN.md` 和部署模板升级；保留服务器原数据目录及外置配置，不覆盖本地项目数据或密钥。

部署与验证入口见 [云部署说明](../CLOUD_DEPLOYMENT.md)。
