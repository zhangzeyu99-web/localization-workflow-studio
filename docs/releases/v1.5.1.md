# v1.5.1 线上部署说明

发布日期：2026-07-16

## 本次变更

- 修复新建项目后，较早发出的项目列表轮询晚返回时把主区切回旧项目的问题。
- 项目列表刷新只接受最后发起的请求结果，旧响应仍可正常结束，但不再覆盖较新的项目列表和当前项目选择。
- 新增确定性浏览器回归测试，覆盖“旧轮询挂起 → 新建项目并选中 → 旧轮询返回”的真实时序。
- 继承 v1.5.0 的账号权限、双通道队列、任务生命周期、归档导入和 cloud 部署能力。

## 升级前准备

1. 备份完整 `/srv/lwstudio/data` 和 `/etc/lwstudio/lws.env`。
2. 解压到新的只读 release 目录，不覆盖 v1.5.0 目录。
3. 从 `PACKAGE_MANIFEST.json` 读取 `git_sha`，写入 `LWS_GIT_SHA`。
4. 保持 `LWS_DATA_ROOT` 指向版本目录外的持久化数据目录。

## 上线步骤

1. 保持单实例、单 uvicorn worker。
2. 原子切换 `/srv/lwstudio/current` 后重启后端，再校验并重载 Nginx。
3. 不要删除 v1.5.0 release，直到 v1.5.1 的登录、项目切换、队列和真实业务流程全部验收通过。

## 上线验收

```bash
PACKAGE_GIT_SHA="$(python3.11 -c 'import json; print(json.load(open("PACKAGE_MANIFEST.json", encoding="utf-8"))["git_sha"])')"
python3.11 scripts/deployment_check.py \
  --base-url https://ai-lwstudio.example.com \
  --require-cloud \
  --require-provider \
  --expect-version 1.5.1 \
  --expect-git-sha "$PACKAGE_GIT_SHA" \
  --check-frontend-assets frontend/dist/assets \
  --auth-user admin \
  --auth-password '管理员密码'

python3.11 scripts/stability_check.py \
  --base-url https://ai-lwstudio.example.com \
  --auth-user admin \
  --auth-password '管理员密码'
```

必须确认：

- 新建项目后主区保持在新项目；后台项目列表轮询返回后不会跳回旧项目。
- `auth_fail_closed` 为 `ok=true`，未登录访问业务 API 返回 401。
- 正式任务与快速任务/公告两条通道可并行，各自 FIFO。
- 公网 HTML、`/api/version` 静态资源清单和包内 `frontend/dist` 一致，版本为 `1.5.1`，Git SHA 与 manifest 一致。
- 管理员登录后的上传探针和完整稳定性流程通过。

## 回滚

保留升级前的完整数据备份和 v1.5.0 release。若需回滚，停止服务后恢复配套的数据备份，再原子切回 v1.5.0；不要只回滚 SQLite 而遗漏上传文件和任务产物。
