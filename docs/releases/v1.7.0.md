# v1.7.0 专名与双源工作流发布说明

发布日期：2026-07-27

## 发布内容

- 标准翻译、AI 审校、workspace runner 和大文本多语言流程新增 `cn`、`cn+en`、`en` 三种显式源模式。
- `cn+en` 以中文为语义主源，英语用于术语、专名、语气和歧义参考；缺少英语参考时逐行回退中文。
- 源模式与英语参考纳入 manifest、缓存、批次签名和深校 checkpoint，避免不同输入模式之间复用错误缓存。
- 术语表明确标记为技能名或地名时，翻译和 QA 启用专名紧凑度、可读性及名称冲突预警；不根据短中文自动误判描述文本。
- 术语提取增加低频专名保留、技能名与地名分类、当前语言表译名优先、交付质量审查包和清洁交付门禁。
- 游戏名继续执行精确术语约束，`Legend of Mushroom` 不允许被复数化、扩写或拆词重组。
- 项目术语回填优先读取本次生成文件的真实目标语言表头，同时兼容历史制品统一使用 `EN` 表头的旧格式。

## 兼容性

- 不变更账号、角色、项目成员和权限模型。
- 不迁移现有 SQLite、项目、上传文件、任务结果或外置 `settings.local.json`。
- 有账号包继续使用 `cloud/required`；无账号包继续锁定为可信公司内网 `cloud/off`。
- 运维仍需解压到全新版本目录，复用版本目录外的 `LWS_DATA_ROOT` 与 `settings.local.json`，不能覆盖旧版本目录。

## 制品

```text
有账号-v1.7.0.zip
有账号-v1.7.0.zip.sha256
无账号-v1.7.0.zip
无账号-v1.7.0.zip.sha256
```

两个包必须来自同一个干净提交和同一份前端生产构建，并具有相同的 `version`、`git_sha_full` 与 `frontend_dist_sha256`。

## 发布验收

- 后端、内嵌术语工作流和内嵌本地化工作流全量测试通过。
- Ruff `E9,F`、Python `compileall`、TypeScript 和 Vite 生产构建通过。
- 有账号和无账号 Playwright E2E 分别通过。
- 两个 ZIP 的包内成员哈希、包外 SHA-256、manifest、敏感文件扫描和全新解压 cloud 模式实跑通过。
- 线上部署不属于本地打包动作；运维切换后仍需从真实域名验证 `/api/version`、`/api/health`、运行 profile、静态资源摘要和缓存响应头。
