# v1.6.3 双云端包发布说明

发布日期：2026-07-24

## 发布内容

- 修复“当前项目翻译提示词”进入编辑后被后台项目轮询强制关闭的问题。
- 同一项目、同一目标语言刷新时保留编辑态和未保存草稿；切换项目或语言时仍会退出旧编辑范围并加载新提示词。
- 同时交付有账号与无账号两个云端部署包，两者来自同一个干净提交和同一份前端生产构建。

## 制品

```text
有账号-v1.6.3.zip
有账号-v1.6.3.zip.sha256
无账号-v1.6.3.zip
无账号-v1.6.3.zip.sha256
```

有账号包是 universal 制品，云端默认使用 `cloud/required`，保留登录、自助注册、管理员用户管理、角色和项目成员权限。部署时使用包内 `deploy/profiles/cloud-required.env.example` 或保持 `deploy/lws.env.example` 的 `LWS_AUTH_MODE=required`。

无账号包是专用 profile 制品，`start-lws.sh`、systemd 服务和环境模板都锁定为 `cloud/off`。它不提供登录、注册、用户、角色或项目成员管理，只允许部署在已有网络隔离的可信公司内网。

## 制品身份

两个包必须满足：

- `version=1.6.3`
- `git_sha`、`git_sha_full` 来自同一个干净提交
- `source_git_dirty=false`
- `contains_settings_local=false`
- `frontend_dist_sha256` 一致
- 包外 `.sha256` 与 ZIP 实际摘要一致
- 包内 `SHA256SUMS.txt`、成员 allowlist、凭据扫描和 manifest readback 全部通过

有账号包：

- `artifact_kind=universal`
- `supported_runtime_profiles=["local-off","cloud-off","cloud-required"]`
- 包内根目录以 `-universal` 结尾

无账号包：

- `artifact_kind=profile`
- `default_runtime_profile=cloud-off`
- `supported_runtime_profiles=["cloud-off"]`
- 包内根目录以 `-cloud-off` 结尾

## 验收

- 后端全量 pytest、Ruff `E9,F`、Python compileall、前端生产构建、Playwright 全量 E2E 与认证 E2E。
- 提示词编辑回归用例覆盖项目详情轮询和窗口聚焦触发的项目列表刷新。
- 两个 ZIP 均从全新目录解压，并分别以 HTTPS `cloud/required`、`cloud/off` 运行部署检查、稳定性流程和 runtime-profile 浏览器冒烟。
- 有账号模式确认匿名业务 API 返回 401、登录/注册可用、Secure session cookie 正常。
- 无账号模式确认匿名业务 API 可用、登录/注册返回 403、设置写入受限且任务操作人昵称继续生效。

## 运维升级

- 解压到全新版本目录，不能覆盖旧目录。
- 继续使用版本目录外的 `LWS_DATA_ROOT` 与 `settings.local.json`。
- 从包内 `PACKAGE_MANIFEST.json` 读取 `git_sha` 设置 `LWS_GIT_SHA`。
- 使用单 worker 后端，原子切换 `current` 后重启。
- 本地生成制品不代表已经部署线上；上线后仍需从真实域名复核 `/api/version`、`/api/health`、缓存响应头和静态资源摘要。
