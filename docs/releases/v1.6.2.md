# v1.6.2 无账号云端版发布说明

发布日期：2026-07-23

## 发布状态与边界

- v1.6.2 增加正式 `cloud/off` profile，并交付锁定为该 profile 的内网无账号线上包。
- 该包只适用于已有网络访问控制的可信公司内网。应用不显示登录、注册、用户、角色和项目成员管理；任何能够访问站点的人都以 synthetic admin 使用业务功能。
- 默认 cloud 行为仍是 `cloud/required`，没有削弱已有账号、角色、项目成员和自助注册能力。
- 本地制品、提交、tag、远端发布与线上部署是独立动作；本文不代表已经推送或部署。

## 制品身份

本次无账号制品名为：

```text
无账号-v1.6.2.zip
无账号-v1.6.2.zip.sha256
```

包内根目录为 `localization-workflow-studio-v1.6.2-g<sha12>-cloud-off`。`PACKAGE_MANIFEST.json` 必须读回核对：

- `artifact_kind=profile`
- `package_policy=profile_runtime_allowlist`
- `version=1.6.2`
- `default_runtime_profile=cloud-off`
- `supported_runtime_profiles=["cloud-off"]`
- `source_state=clean_git_commit`
- `git_sha`、`git_sha_full` 与本次干净提交一致
- `contains_settings_local=false`
- `frontend_dist_sha256`、`runtime_payload_sha256` 与解压内容一致

包外 `.sha256`、包内 `SHA256SUMS.txt`、成员 allowlist、凭据扫描和 manifest identity 都必须通过 readback。

## 无账号云端运行边界

- `start-lws.sh`、`deploy/lws.service` 和 `deploy/lws.env.example` 同时锁定 `LWS_DEPLOYMENT_MODE=cloud`、`LWS_AUTH_MODE=off`。
- 无账号环境模板与部署说明不要求 `LWS_ADMIN_USER`、`LWS_ADMIN_PASSWORD` 或账号登录参数；制品不包含数据库、上传文件、任务产物、日志、Git 数据或 `settings.local.json`。
- 专用制品只保留 Linux `cloud/off` 启动与验收入口，不携带 Windows `local/off` 启动器、管理员创建脚本或其它 profile 模板。
- `LWS_DATA_ROOT` 和 `settings.local.json` 必须放在 release 目录之外；前端只使用包内已验证的 production dist。
- 匿名业务 API 可用；`/api/auth/me` 返回 `auth_enabled=false` 的 synthetic admin；登录和注册接口返回 403。
- cloud 数据目录保护、网页设置只读、API/HTML 缓存策略、静态资源身份校验和 AI 任务操作人昵称要求继续生效。
- 运行在该 profile 时没有用户和项目成员隔离，必须由内网、VPN、网关白名单等外层能力限制访问。

## 术语与公告能力

- 公告术语准备增加官方完整句式模板层，在单个术语前优先提供官方句式和相似语境证据。
- 句式回填保留占位符，能够把公告实际值安全套入官方译文。
- 对没有沿用官方完整句式的译文输出一致性警告，不改变既有公告工作流的成功退出语义。

## 验收门禁

Source gates 至少包括后端全量 pytest、workflow 专项测试、Ruff `E9,F`、Python `compileall`、前端 production build、Playwright 全量 E2E 与认证 E2E。

打包命令：

```powershell
python scripts/build_release_package.py --output-dir release_archives --no-rebuild-frontend --no-account
```

必须从全新解压目录用外置临时数据目录启动 `cloud/off`，在 HTTPS 同域入口完成：

- `/api/version`、`/api/health` 与 manifest 的版本、Git SHA、profile 和前端摘要一致。
- 匿名项目 API 为 200，登录/注册为 403，网页设置修改为 403。
- deployment check、完整 stability flow、runtime-profile Playwright 和清理检查通过。
- ZIP 外部 SHA-256、包内成员哈希、敏感文件扫描和 Linux 启动脚本语法通过。

当前 GitHub Actions 的 publish gate 只覆盖 universal 制品，不能作为本次专用包证据；以上 no-account 打包与 extracted HTTPS 验收必须在本地单独完成并读回。

## 运维升级

- 解压到全新版本目录，不能覆盖当前目录。
- 继续使用外置 `LWS_DATA_ROOT` 和 `settings.local.json`。
- 从 `PACKAGE_MANIFEST.json` 读取 `git_sha` 设置 `LWS_GIT_SHA`。
- 使用单 worker 后端，原子切换 `current` 后重启服务。
- 上线后按 `docs/CLOUD_DEPLOYMENT.md` 的 `cloud/off` 命令验收；本次任务不代替运维执行线上部署。
