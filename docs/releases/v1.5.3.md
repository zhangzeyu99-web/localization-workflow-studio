# v1.5.3 线上部署说明

## 本版修复

- 账号部署不再显示旧的昵称设置入口，操作人统一使用登录账号。
- 项目成员弹窗增加加载状态，不再在数据返回前闪现空列表。
- 后端拒绝把停用账号或管理员加入项目成员，不能再绕过前端候选列表。
- 首次改密拒绝继续使用当前密码；新建用户名统一限制为 128 个字符。
- 管理员修改用户角色后撤销该用户旧会话，避免页面继续显示旧权限。
- 当前管理员在用户管理页不能操作自己的角色和启停状态，避免无效操作。

## 运维部署要求

1. 备份当前数据目录和旧版本目录。
2. 把 `有账号-v1.5.3.zip` 解压到全新的版本目录，禁止覆盖旧目录。
3. 保留线上外置 `settings.local.json` 和数据目录，不要从包内生成替代文件。
4. 设置 `LWS_GIT_SHA` 为包内 `PACKAGE_MANIFEST.json` 的 `git_sha`，单 worker 启动后原子切换 `current`。
5. 验证 `/api/version` 的版本、Git SHA 和静态资源清单与包内完全一致。

```bash
PACKAGE_GIT_SHA="$(python3.11 -c 'import json; print(json.load(open("PACKAGE_MANIFEST.json", encoding="utf-8"))["git_sha"])')"
export LWS_GIT_SHA="$PACKAGE_GIT_SHA"

python3.11 check.py \
  --base-url https://ai-lwstudio.example.com \
  --require-cloud \
  --require-provider \
  --expect-version 1.5.3 \
  --expect-git-sha "$PACKAGE_GIT_SHA" \
  --check-frontend-assets frontend/dist/assets \
  --auth-user admin \
  --auth-password '管理员密码'
```

部署后确认账号登录、首次改密、项目成员加载、角色变更重新登录，以及双通道队列均正常。
