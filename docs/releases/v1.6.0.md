# v1.6.0 历史候选说明

> **历史状态：** v1.6.0 是统一前的账号线候选，已由 v1.6.1 的单版本、双运行配置模型取代。以下内容保留当时事实，不代表当前产品边界或已完成线上部署。

发布日期：2026-07-20

## 发布状态与版本边界

- 本文用于准备 v1.6.0 有账号版发布；实施前实测线上仍为 v1.5.1，不能据此宣称 v1.6.0 已上线。
- 本次只更新有账号版。无账号版保持 v1.5.2 不变，不重建、不覆盖，也不删除其现有发布物。
- v1.6.0 与现有用户、项目和数据兼容，无需迁移数据库或业务文件。

## 用户可见变化

- 未登录访客只能看到登录页和注册页，不能进入工作台或查看项目数据。
- 自助注册成功后立即创建启用状态的 `member` 账号并建立登录会话；注册不会自动加入既有项目，但可按现有流程新建项目并自动成为该项目成员，也可由管理员或有权限的运营人员分配既有项目。
- 登录与注册切换会丢弃过期请求结果，避免较晚返回的旧请求覆盖当前页面或会话。
- 管理员用户列表显示注册时间和最近登录时间，并把列表刷新与账号操作的加载状态分开。

## 运维部署要求

1. 备份当前版本目录、外置数据目录和环境配置。
2. 整分支验证通过并生成发布包后，把有账号版 v1.6.0 解压到全新的 release 目录；禁止覆盖旧版本目录。
3. 保持 `LWS_DATA_ROOT` 指向 release 目录之外的持久目录，并继续使用 `$LWS_DATA_ROOT/settings.local.json`；不要把线上数据或配置复制进新 release。
4. 从包内 `PACKAGE_MANIFEST.json` 读取 `git_sha` 并设置 `LWS_GIT_SHA`，不得用人工记忆的提交号代替 manifest。
5. 保持单实例、单 uvicorn worker。完成包内检查后，原子切换 `/srv/lwstudio/current`，再重启后端并校验、重载 Nginx。

执行前，将 `REPLACE_WITH_GIT_SHA` 替换为本次 release 目录名中的实际 Git SHA：

```bash
set -euo pipefail

release=/srv/lwstudio/releases/20260720-REPLACE_WITH_GIT_SHA
cd "$release"
PACKAGE_GIT_SHA="$(python3.11 -c 'import json; print(json.load(open("PACKAGE_MANIFEST.json", encoding="utf-8"))["git_sha"])')"
env_file=/etc/lwstudio/lws.env
if sudo grep -q '^LWS_GIT_SHA=' "$env_file"; then
  sudo sed -i "s/^LWS_GIT_SHA=.*/LWS_GIT_SHA=$PACKAGE_GIT_SHA/" "$env_file"
else
  printf 'LWS_GIT_SHA=%s\n' "$PACKAGE_GIT_SHA" | sudo tee -a "$env_file" >/dev/null
fi
sudo grep -Fx "LWS_GIT_SHA=$PACKAGE_GIT_SHA" "$env_file"

sudo ln -sfn "$release" /srv/lwstudio/current.next
sudo mv -Tf /srv/lwstudio/current.next /srv/lwstudio/current
sudo systemctl restart lws.service
sudo nginx -t && sudo systemctl reload nginx
```

## 上线验收

下列验收代码块可在新的 shell 中独立执行；同样先替换 release 目录名中的 `REPLACE_WITH_GIT_SHA`：

```bash
set -euo pipefail

release=/srv/lwstudio/releases/20260720-REPLACE_WITH_GIT_SHA
cd "$release"
PACKAGE_GIT_SHA="$(python3.11 -c 'import json; print(json.load(open("PACKAGE_MANIFEST.json", encoding="utf-8"))["git_sha"])')"

python3.11 scripts/deployment_check.py \
  --base-url https://ai-lwstudio.example.com \
  --require-cloud \
  --require-provider \
  --expect-version 1.6.0 \
  --expect-git-sha "$PACKAGE_GIT_SHA" \
  --check-frontend-assets frontend/dist/assets \
  --auth-user admin \
  --auth-password '管理员密码'
```

必须确认未登录只显示登录/注册界面，注册账号为启用的普通成员且没有自动加入既有项目，并能新建项目后成为该项目成员；已有账号和项目应可正常使用。同时核对公网版本、Git SHA、静态资源、外置数据目录和单 worker 状态。完成这些线上验收后，才能记录 v1.6.0 已部署。
