# v1.3.4 线上部署说明

发布日期：2026-07-15

## 本次变更

- 修复中文及其他非拉丁字符昵称随 API 请求发送时触发浏览器 `Headers` ISO-8859-1 错误的问题。
- 后端会将传输用编码还原为原始昵称，任务事件、活跃任务和冲突提示继续显示真实昵称。
- 增加中文昵称创建项目和创建运行任务的前后端回归测试。

## 运维部署

1. 将部署包解压到全新的版本目录，不要覆盖旧版本目录；保留版本目录之外的持久化数据目录与 `/etc/lwstudio/settings.local.json`。
2. 从 `PACKAGE_MANIFEST.json` 读取 `git_sha`，写入 `/etc/lwstudio/lws.env` 的 `LWS_GIT_SHA`。
3. 原子切换 `current` 软链接到新版本目录，再重启后端服务。
4. 按包内 `deploy/README-ops.md` 运行部署检查，确认 `/api/version` 的版本为 `1.3.4`、Git SHA 一致，并且线上静态资源清单与包内 `frontend/dist/assets` 完全一致。
5. 使用中文昵称新建项目并启动一次任务，确认页面不再出现 `String contains non ISO-8859-1 code point`。

若页面显示“前端/后端版本不一致”，说明新前端已生效但后端仍是旧进程，或代理返回了旧的 `/api/version`。不要继续叠加覆盖文件；确认 `current` 指向本次完整发布目录、重启服务，并检查 API/HTML 的缓存策略。
