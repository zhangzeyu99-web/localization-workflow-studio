# v1.7.1 译文归档身份兼容修复说明

发布日期：2026-07-28

## 修复内容

- 允许不同翻译 ID 使用相同的规范化中文源文，不再把这种合法数据误判为“同一中文对应多个 ID”。
- 已有 ID 导入时以 ID 作为稳定身份更新对应记录；即使另一条有 ID 记录使用相同中文源文，也不会阻断导入。
- 同一 ID 跨语言共享中文源文时继续同步概念源文，并保留各语言已有译文。
- 首次导入和再次导入都能按 ID 独立新增或更新同源文记录。
- 有 ID 与无 ID 记录混用同一源文仍然视为身份冲突，原有保护保持不变。

## 兼容性

- 不变更账号、角色、项目成员和权限模型。
- 不迁移现有 SQLite、项目、上传文件、任务结果或外置 `settings.local.json`。
- 有账号包继续使用 `cloud/required`；无账号包继续锁定为可信公司内网 `cloud/off`。
- 运维仍需解压到全新版本目录，复用版本目录外的 `LWS_DATA_ROOT` 与 `settings.local.json`，不能覆盖旧版本目录。

## 制品

```text
有账号-v1.7.1.zip
有账号-v1.7.1.zip.sha256
无账号-v1.7.1.zip
无账号-v1.7.1.zip.sha256
```

两个包必须来自同一个干净提交和同一份前端生产构建，并具有相同的 `version`、`git_sha_full` 与 `frontend_dist_sha256`。

## 发布验收

- 归档批次回归测试覆盖首次导入、跨语言更新、已有 ID 采用共享源文和同源文独立重导。
- 后端、内嵌术语工作流和内嵌本地化工作流全量测试通过。
- Ruff `E9,F`、Python `compileall`、TypeScript 和 Vite 生产构建通过。
- 有账号和无账号 Playwright E2E 分别通过。
- 两个 ZIP 的包内成员哈希、包外 SHA-256、manifest、敏感文件扫描和全新解压 cloud 模式实跑通过。
