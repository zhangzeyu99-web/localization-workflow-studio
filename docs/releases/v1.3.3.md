# v1.3.3 线上部署说明

发布日期：2026-07-14

## 本次变更

- 顶部新增独立的“操作人昵称”入口，线上隐藏“设置”按钮时仍可使用。
- 线上启动或继续翻译、QA、模型修复、公告翻译、多语言队列前必须设置昵称。
- 活跃任务列表展示操作人；同一项目被占用时直接提示当前任务由谁执行。
- 昵称只用于任务归属与协作提示，不是账号系统，不改变用户权限。

## 运维部署

1. 使用本版本部署包覆盖应用代码，保留服务器现有持久化数据目录与 `settings.local.json`。
2. 按包内 `deploy/README-ops.md` 执行安装/更新步骤。
3. 重启服务后访问 `/api/version`，确认前后端均为 `1.3.3` 且 Git SHA 一致。
4. 使用两个浏览器分别设置不同昵称，启动同一项目的任务，确认第二个浏览器能看到当前操作人和冲突提示。

SQLite 会在首次启动时为 `job_leases` 自动增加 `operator_name` 字段，不需要手工执行数据库脚本。旧的运行记录没有昵称时显示“未署名用户”。
