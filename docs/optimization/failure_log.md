# 工作台失败轨迹库

## 使用规则

这里记录真实用户遇到过、或验证集复现过的问题。它不是流水账，只有会影响用户完成任务的问题才写入。

每条记录必须能回答四件事：

1. 用户看到什么。
2. 实际哪里坏了。
3. 怎么修。
4. 怎么防止再坏。

新增失败后，优先判断是否需要补到 `validation_set`；如果需要改产品或流程，再同步写入 `improvement_backlog.md`。

## 记录模板

```text
## F-YYYYMMDD-编号 问题标题

- 日期：
- 流程：
- 用户看到的现象：
- 实际根因：
- 影响范围：
- 修复方式：
- 回归验证：
- 是否已加入验证集：
- 关联改进建议：
```

## F-202606-001 上传失败只显示 Failed fetch

- 日期：2026-06
- 流程：新翻译 / 术语导入 / 项目资料上传
- 用户看到的现象：页面状态只显示 `上传失败：Failed to fetch`，不知道是文件太大、后端错误还是网络问题。
- 实际根因：前端没有把后端错误结构转成人话提示；部分 nginx/后端错误返回 HTML，前端直接展示原始内容。
- 影响范围：所有上传入口。
- 修复方式：上传接口错误统一解析；如果是 413，提示文件过大；如果是格式问题，提示应该上传到哪个步骤；禁止直接展示 HTML。
- 回归验证：运行 `validation_set/cases/008_cloud_deployment_smoke.md` 和任一上传类 case。
- 是否已加入验证集：是。
- 关联改进建议：I-001。

## F-202606-002 后端 traceback 暴露到前端

- 日期：2026-06
- 流程：公告任务 / AI 分析 / 术语提取
- 用户看到的现象：页面顶部展示 Python command、traceback、服务器路径或大段技术错误。
- 实际根因：subprocess 和异常处理没有统一转成用户可读错误。
- 影响范围：所有调用 workflow 脚本或 provider 的流程。
- 修复方式：前端只展示摘要；后端把详细日志写入后台 artifact 或日志，不直接透出给用户。
- 回归验证：构造格式错误文件，确认页面只显示人话错误和下一步。
- 是否已加入验证集：是。
- 关联改进建议：I-002。

## F-202606-003 交付文件下载 Not Found

- 日期：2026-06
- 流程：新翻译 / QA / 公告交付 / 快速任务
- 用户看到的现象：交付页显示文件名，但点击下载返回 `{"detail":"Not Found"}`。
- 实际根因：artifact 记录与真实文件路径不一致，或交付页引用了过程产物/旧产物。
- 影响范围：所有最终交付入口。
- 修复方式：交付生成后必须登记最终 artifact；交付页只展示可下载的最终产物；下载前校验文件存在。
- 回归验证：运行 001、002、006、007，逐个点击下载。
- 是否已加入验证集：是。
- 关联改进建议：I-003。

## F-202606-004 完整语言表误进项目术语库

- 日期：2026-06
- 流程：术语表导入 / 新翻译 STEP4/STEP5 / 公告约束

## F-202606-009 删除项目失败

- 用户看到的现象：确认删除后提示 `project not found`，项目仍显示或页面状态混乱。
