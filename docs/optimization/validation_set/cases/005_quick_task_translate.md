# 005 快速任务翻译

## 任务目标

验证用户不进入 9 步工作轴，也能通过快速任务完成一次轻量翻译，并能查看结果。

## 输入文件

- XLSX/CSV/TXT 中一种。
- 若是语言表，包含 `ID`、`CN`。
- 可选参考文件：术语表、风格说明或项目 brief。

## 操作路径

1. 选择当前项目。
2. 点击侧边栏“快速任务”。
3. STEP1 上传待处理文件。
4. STEP2 上传可选参考，或直接跳过。
5. STEP3 选择“翻译”和目标语言。
6. 点击开始翻译。
7. 查看任务进度。
8. 完成后点击查看结果和下载。

## 通过标准

- 没有 9 步轴。
- 目标语言能自动识别，识别不到时可手动选。
- 任务中断后可以继续，不重复创建一堆 run。
- 完成后项目历史能追踪该快速任务。
- 下载结果不返回 `Not Found`。

## 失败信号

- 点击开始后展示一大段代码或 traceback。
- 状态只显示 running，但无进度、无取消、无继续。
- 完成后找不到结果。
- 快速任务污染项目长期术语库。

## 清理方式

删除测试项目，或在项目历史中确认测试 run 可识别。
