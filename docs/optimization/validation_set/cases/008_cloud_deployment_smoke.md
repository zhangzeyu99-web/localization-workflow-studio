# 008 线上基础 smoke

## 任务目标

验证线上或局域网部署不是“页面能打开”，而是上传、下载、任务状态和数据目录都真正可用。

## 输入文件

- 小型 TXT/MD 项目资料。
- 小型 XLSX/CSV 语言表。
- 可选公告 TXT。

## 操作路径

1. 打开线上或局域网 URL。
2. 检查 `/api/version`。
3. 检查 `/api/health`。
4. 新建测试项目。
5. 上传项目资料。
6. 上传语言表。
7. 运行一次轻量 QA 或翻译 smoke。
8. 下载任意生成产物。
9. 删除测试项目。

## 通过标准

- `/api/version` 返回当前版本和 commit。
- `/api/health` 显示 data root 可写、数据库可连。
- 上传不返回 413 或 Failed fetch。
- 产物下载不返回 `Not Found`。
- 删除测试项目成功。
- 页面不暴露服务器路径、traceback 或 API key。

## 失败信号

- 前端是新版，后端接口是旧版。
- `/api/version` 404。
- 上传成功但后端读不到文件。
- 删除项目失败。
- 线上数据目录写入仓库目录或静态目录。

## 清理方式

必须删除测试项目；如果删除失败，手动记录项目名和时间，进入失败轨迹库。
