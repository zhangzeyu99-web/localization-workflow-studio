# 004 多语言译文归档导入导出

## 任务目标

验证用户在项目概览“译文归档”中导入多语言表后，归档能正确显示、搜索、分页和导出。

## 输入文件

- XLSX/CSV。
- 必须包含 `ID`、`CN`。
- 可包含 `EN`、`EN2`、`KR`、`JP` 中的一列或多列。

## 操作路径

1. 打开项目概览。
2. 进入“译文归档”页。
3. 点击“导入译文”。
4. 上传多语言译文表。
5. 等待自动导入完成。
6. 使用搜索框搜索 ID、CN、译文。
7. 勾选语言列，确认对应列显示。
8. 导出单语言 XLSX/CSV。
9. 导出全语言 XLSX/CSV。

## 通过标准

- 导入后归档数量增加。
- EN/KR/JP 不互相覆盖。
- 搜索为连续强匹配。
- 每页最多展示 100 行。
- 导出的文件能打开，表头符合语言展示口径。

## 失败信号

- 导入按钮无反馈。
- 导入成功但表格为空。
- KR/JP 显示成 KO/JA 且与项目口径不一致。
- 导出 JSON 出现在用户入口。
- 下载返回 `Not Found`。

## 清理方式

删除测试项目，或导出后清理测试归档。
