# 003 完整语言表生成术语候选

## 任务目标

验证完整语言表不会直接进入项目术语库，只能通过扫描生成候选，人工确认后才入库。

## 输入文件

- 一份完整语言表。
- 必须包含 `ID`、`CN`、至少一个目标语言列，例如 `EN`、`KR`、`JP`。
- 行数建议大于 1000，用于触发完整语言表识别。

## 操作路径

1. 在新翻译任务 STEP4 上传完整语言表。
2. 进入 STEP5“术语候选”。
3. 点击扫描术语候选。
4. 查看候选列表。
5. 人工选择若干候选并确认入库。
6. 返回项目概览的术语表页查看。

## 通过标准

- 上传完整语言表到“项目术语表导入”时会被拦截。
- STEP5 能用完整语言表生成候选。
- 生成候选时不直接增加项目术语表数量。
- 人工确认后，项目术语表出现对应术语。
- 目标语言列自动识别，例如 KR 表不会按 EN 扫描。

## 失败信号

- 完整语言表被一次性导入项目术语库。
- 候选扫描报缺少 `input_artifact_id`、`project_name` 等技术字段。
- KR/JP 表被错误当成 EN。
- UI 提示成功，但术语表仍为空。

## 清理方式

删除测试项目；如果已污染术语库，记录污染条件并清理测试数据。
