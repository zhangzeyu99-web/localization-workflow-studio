# 002 已有译文表直接 QA

## 任务目标

用户上传一份已经带译文的语言表，不走 AI 翻译，直接进入 QA、修复和交付。

## 输入文件

- XLSX/CSV。
- 必须包含 `ID`、`CN`、目标语言列，例如 `EN`、`KR` 或 `JP`。
- 至少 10 行已有译文。

## 操作路径

1. 创建或选择测试项目。
2. 进入“启动新翻译任务”。
3. STEP4 上传已有译文表。
4. 系统判断这是“已译校对表”。
5. 跳过模型翻译，进入 QA。
6. 运行 QA。
7. 如果存在 hard block，查看问题；可以下载问题交付或修复后重跑。
8. 生成最终交付。

## 通过标准

- 页面明确提示“已有译文，可直接校对”。
- 不要求用户再点击 AI 翻译。
- QA 失败时有问题列表和修复入口。
- QA 通过或允许问题交付时，能生成交付文件。

## 失败信号

- 已有译文表仍被当作空表要求翻译。
- QA 运行中卡住，用户看不到进度。
- failed 后没有任何可操作入口。
- 最终没有交付包，也没有解释原因。

## 清理方式

删除测试项目，或删除该 QA run 的测试产物。
