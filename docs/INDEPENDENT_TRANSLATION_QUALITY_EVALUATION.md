# 独立翻译质量评估入口

工作流维护规范位于 `D:\project\localization-workflow-project\docs\INDEPENDENT_TRANSLATION_QUALITY_EVALUATION.md`。独立质量评估和深校复盘须先读取该规范。

主要验收要求：

- 每次重新扫描项目资料，先审成品，再看旧审校理由。
- 同批已批准的姓名行必须进入临时术语快照；正式交付和正式术语表保持只读。
- 对白语义审读区分说话者、受话者与语法先行词；来源不足的性别调整不得凭猜测采纳。
- 二次审计器必须接收主控提供的源文、原译和上下文；审查真实请求数据，不能只看提示词宣称。
- 分别报告结构检查、固定样本语义评分、定向扩查、误报以及深校引入的退化。测试通过和模型语义能力分开验收。
